## 零、产品定义

### 这是什么

一个**活的修仙世界模拟器**。不是聊天机器人，不是 AI 编剧，不是填表单的网页游戏。

你把你自己投入一个正在运转的修仙世界。这个世界里，NPC 有自己的性格、日程、私心和记忆。宗门在运作，坊市在交易，势力在角逐。你只是这个世界的一个参与者——甚至是一个干扰者。

你打字，世界回应你。但世界不围着你转。

### 核心设计信仰

1. **模拟器，不是舞台** — NPC 不等你点对话。状态机驱动日常行为，LLM 只在决策点唤醒
2. **知识气泡** — 你一个人在山洞里捡到功法，没有任何 NPC 应该知道。除非你告诉别人，或者有人看见了
3. **脑体分离** — LLM 是脑（高层决策），行为树/状态机是身体（日常执行）
4. **玩家是参与者，不是主角** — 你可以拜师、抢劫、欺骗、谈判、攻打宗门。但对方同不同意，是另一个 AI（或状态机）决定的
5. **Token 即成本，叙事即价值** — 没有废话。AI 的每个字都在推进剧情或揭示世界

### 参考作品

- 《觅长生》— 横向时间 + 闭关系统 + NPC 自主决策
- GTA V / RDR2 — 分区人口 + 五级优先级中断 + NPC 原型+参数变异
- 斯坦福 Generative Agents (Smallville) — 记忆流→检索→反思→规划
- Claude Code — Agent = for 循环，复杂度在世界层

### Agent 生命周期（GUARD → THINK → ACT → SAVE）

```
GUARD  防重 + 加载玩家 + 广播 accepted
THINK  RAG检索(可降级) + 复杂度估算 + 计划制定(简单输入跳过)
ACT    [循环] 组装上下文 → LLM推理 → 文本流输出 → 工具执行
       自修正: 工具校验失败不报废回合, 注入错误让LLM重试
       终止: LLM不调工具(done) / 达到轮次上限(hardLimit) / 取消
SAVE   构建快照 + 原子提交 + 广播 state_update/completed
```

### 当前最大债务

**世界层有基础骨架，但行为树和记忆流仍为空。** 我们有一个能跑通的 Agent 循环，能调工具、能过闸门、能流式输出文本。但 NPC 没有行为树，没有日计划，没有知识气泡，没有记忆流。`region-state.ts` 只是一个数据查询单例，不是设计文档里描述的 Region DM。

我们现在的状态：**Agent 循环是一个精美的壳，里面没有世界。**

## 四、开发规则

1. **先读本日志** — 每次开始工作前，先读本文件确认当前进度和优先级
2. **设计文档是真理** — `docs/architecture-brainstorm-log.md` 和核心技术架构文档包含了完整设计，实现前先对照
3. **不改无关代码** — 只改任务要求的部分，不"顺便优化"
4. **测试先行** — 任何逻辑变更先写测试，红→绿→重构
5. **完成即更新本日志** — 每完成一个模块，更新上面的实现状态表
6. **竖切优先** — 不做"全部设计完再动手"，做"最小可用→验证→迭代"
