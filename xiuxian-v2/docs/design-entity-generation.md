# 实体生成触发条件设计：预种子 + 按需生成

> 日期：2026-07-25
> 状态：设计阶段（待实现）
> 关联：上下文编排设计、UI面板数据绑定

---

## 问题诊断

当前实体生成完全由 LLM 自行决定，没有任何规则约束：

1. **重复生成**：LLM 在 planning 阶段决定"生成一个宗门"，调用 GenerateSect。下回合又决定"生成一个宗门"，再次调用。没有机制告诉它"金剑门已经存在了"。
2. **每次开局全量生成**：每次新游戏 LLM 都要生成所有宗门/地点/物品，消耗大量 token。
3. **生成质量不稳定**：LLM 每次生成的结果不一致，同一个宗门名字/描述每次不同。

**根因**：没有把"世界基础设施"和"会话动态内容"分开。前者应该是稳定的、可复用的；后者才是每次动态生成的。

---

## 设计方案：双层实体系统

```
┌──────────────────────────────────────────────┐
│          世界基础设施层（预种子 + 持久化）        │
│                                              │
│  来源：手动编写的高质量种子数据                   │
│  存储：world_state 表（独立于玩家存档）           │
│  生命周期：永久，除非世界演化事件更新              │
│  内容：宗门、地点、物品模板、功法                  │
│                                              │
│  AI行为：从已有的基础设施中选择最匹配的，           │
│          只有不匹配时才生成新的                   │
└──────────────────────────────────────────────┘
         │
         │ 加载
         ▼
┌──────────────────────────────────────────────┐
│          会话动态层（per-save）                 │
│                                              │
│  来源：LLM动态生成 / 从基础设施中选择             │
│  存储：player 的 JSON 字段                     │
│  生命周期：存档期间                              │
│  内容：NPC实体、剧情事件、伏笔、关系              │
│                                              │
│  AI行为：NPC每次新生成，事件动态编排              │
└──────────────────────────────────────────────┘
```

## 触发条件规则

| 场景 | 行为 | 消耗 |
|------|------|------|
| 游戏开局 | 从种子数据中选择最匹配的宗门/地点，不调用LLM生成 | 0 token |
| 玩家到达种子数据中已有的区域 | 直接从种子数据加载，注入上下文 | 0 token |
| 玩家到达种子数据中没有的区域 | LLM生成新地点，持久化到世界层 | ~200 token |
| 玩家遇到新NPC | LLM生成NPC（NPC不预种子） | ~150 token |
| 玩家需要种子数据中没有的物品 | LLM生成新物品模板，持久化到世界层 | ~100 token |
| 世界大事件改变已有实体 | 更新实体字段，不新建 | 0 token |
| LLM在叙事中随口提到一个新名字 | **不自动创建实体**，必须通过工具调用显式创建 | 0 token |

### 核心规则

**"选择优于生成"**：
1. AI 需要宗门 → 先从种子数据中查找最匹配的 → 找到 → 直接使用
2. AI 需要地点 → 先从种子数据中查找 → 找到 → 直接使用
3. 找不到匹配的 → 才调用 Generate 工具，创建新实体
4. 新创建的实体持久化到世界层，下次可直接复用

## 预种子数据规模

| 类别 | 数量 | 说明 |
|------|------|------|
| 宗门 | 6个 | 覆盖正道/魔道/中立，不同规模 |
| 地点 | 6个 | 覆盖安全区/野外/城市/险地 |
| 物品模板 | 15件 | 丹药、法宝、材料、杂物 |
| 功法 | 8本 | 主修功法、战斗技能、身法、辅助 |

### 宗门种子示例

```typescript
{
  name: '金剑门',
  alignment: '正道',
  power_level: '二流宗门',
  master: '金剑真人',
  master_realm: '金丹期',
  description: '以剑修为主的宗门，门规森严，弟子多为剑修，崇尚"一剑破万法"。',
  specialties: '剑道、金系功法',
  reputation: '南域有名的剑修门派，与其他正道宗门关系良好',
}
```

### 地点种子示例

```typescript
{
  name: '青云坊市',
  region: '南域',
  danger_level: '安全',
  description: '青云山脉脚下最大的修仙者集市，各色修士往来不绝，店铺林立。',
  features: ['丹药铺', '法宝阁', '任务堂', '茶楼'],
  connected_to: ['金顶峰', '苍澜山', '黑木林'],
}
```
