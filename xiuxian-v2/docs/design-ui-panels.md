## 总览

所有面板数据已存在于 Zustand store (`src/stores/game.ts`)，改动主要是数据绑定和UI增强。

## 一、StatusPanel（右侧属性面板）

### 当前
- HP/MP/寿元进度条
- 神识数值
- 背包前5件物品预览

### 需要新增

```
┌─────────────────────────┐
```

### 数据来源
- 当前位置：`player.currentLocation`
- 在场NPC：`player.npcs.filter(n => n.currentLocation === player.currentLocation)`
- 游戏时间：`player.worldTime` → `formatWorldTime()`
- 活跃事件：`player.situations.filter(s => s.status !== 'ended')` → 从 `state_update` SSE 事件同步

## 二、CodexPanel（图鉴）

### 当前
- 按类型分组（人物/地点/物品/宗门）
- 简单的名称+描述卡片

### 需要新增

1. **顶部搜索框** — 实时过滤
2. **类型标签栏** — 全部/人物/地点/物品/宗门的 tab 切换
3. **条目点击展开** — 显示完整 metadata
   - 地点：危险等级、关联区域、居民、规则
   - NPC：境界、宗门、性格、好感度
   - 物品：品级、类型、效果
   - 宗门：阵营、掌门、势力等级
4. **关联跳转** — 从NPC条目跳转到其宗门条目

### 数据来源
- `player.codex` — 由 `codex` SSE 事件实时追加
- 按 `entry_type` 分组，按 `name` 搜索过滤

## 三、BackpackPanel（背包）

### 当前
- 物品列表，按品级显示颜色
- 名称、类型、品级、数量、价值

### 需要新增

1. **物品点击弹窗** — 显示完整描述 + 操作按钮
2. **"使用"按钮** — 丹药类物品 → 发送 `ConsumeItem` 到后端
3. **排序选项** — 按品级/类型/名称排序

### 数据来源
- `player.inventory` — 由 `state_update` SSE 事件同步
- 使用物品 → 通过 `useGameStream.send()` 发送 action

## 四、StatsDetailPanel（属性详情）

### 当前
- 基础信息（境界、灵根、阵营、宗门、种族）
- 战斗数据（神识）
- 功法信息
- 装备（当前为空，无数据）
- 天赋与特质

### 需要新增

1. **运势/因果数值** — `player.stats.fortune` 和 `player.stats.karma`，当前数据已有但未展示
2. **神识描述文字** — `player.stats.spirit.desc`，当前只显示数值
